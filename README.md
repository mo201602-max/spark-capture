# スパークキャプチャ 0.1（試作）

[Android用APKをダウンロード](https://github.com/mo201602-max/spark-capture/raw/refs/heads/main/downloads/sparkcapture-0.1.apk) · [リリース一覧](https://github.com/mo201602-max/spark-capture/releases)

インパルス試験の放電箇所を確認するためのAndroid用カメラアプリ。
Android 8.0以降、背面カメラを想定。特定メーカーの独自機能や通信は不要です。

## 使い方

1. sparkcapture-0.1.apk をAndroid端末にコピーして開き、インストールします。
   必要に応じて、APKを開いたアプリに対する「不明なアプリのインストール」を許可します。
2. カメラを許可し、対象を画面に収めます。
3. 15・30・60fpsから希望速度を選択します。初期値は30fpsです。
   実際の速度は画面の「実測fps」で確認します。端末が対応しない速度は近い設定になります。
4. 「待機中」になってから試験します。音を聞いたら「直前1秒を保存」を押します。
5. 直前1秒以内にアプリが受け取った画像だけが保存されます。ボタン以降の画像は入りません。
6. スライダーで1コマずつ確認できます。
7. 「ZIPを書き出す」で保存先を指定すると、複数人で画像を共有できます。
8. 「撮影を再開」で次の試験を待ちます。過去の撮影は「保存済みZIPを選ぶ」で書き出せます。

## 保存内容

- 白黒JPEG画像。640×480に面積が近い、端末の対応解像度を使用します。
- timing.csv：画像名、ボタン時点に対する画像受信時刻（ミリ秒・負値）、カメラのセンサー時刻（ns）。
- 撮影ごとのZIPをアプリ内部にも保存します。アプリのデータ削除やアンインストールで消えます。
  保存数の自動削除機能はありません。必要なデータを書き出してからデータを整理してください。

## 技術上の制限と検証状況

- ソースのコンパイル、DEX生成、APK生成、APK署名検証を実施しました。
- 実機・エミュレータでの動作検証、端末間互換性、スパーク捕捉の検証は未実施です。
- 15fpsは約67ms、30fpsは約33ms、60fpsは約17ms間隔です。
  短い放電はフレーム間や露光の外に入り、どのコマにも写らない場合があります。
- 60fpsは通常のCamera2セッションに対応する端末でのみ利用できます。
  専用の高速撮影セッション、固定露光、手動フォーカスには対応していません。
- 明るさ、露光時間、画像処理負荷により実測fpsは変わります。
- 画像受信時刻はセンサーの露光時刻そのものではありません。直前1秒は受信時刻基準です。
  timing.csvのセンサー時刻は端末依存の時計基準なので、外部試験装置との同期には使えません。
- 押す前の画像しか保存しないため、音からボタン操作まで1秒を超えるとイベントは保存範囲外になります。
- 白黒なのでスパークの色は記録しません。アプリを離れると撮影を停止します。

## ソースからのビルド

このフォルダをAndroid Studioで開きます。Android SDK 35、JDK 17以降を用意し、
Gradle 8.9 / Android Gradle Plugin 8.7.3で同期してAPKをビルドしてください。
本配布APKは試作用のローカル鍵で署名しています。鍵はソースZIPには含めていません。
