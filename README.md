# 1秒前カメラ 0.4

[Android用APKをダウンロード](https://github.com/mo201602-max/spark-capture/raw/refs/heads/main/downloads/sparkcapture-0.4.apk)

直前1秒を切り取り、スライダーで動かすカメラ。Android 8.0以降に対応します。
前版に上書きインストールできます。黄色と紺のカメラ＋「！」アイコンが目印です。
右下の「写真を共有」ボタンは削除しました。1枚保存後に開く共有メニューは引き続き使えます。

## 操作

- **丸いシャッター**：直前1秒を確定。
- **スライダー／◀ ▶**：コマを選択。
- **再生／速度**：正再生と逆再生を繰り返す往復ループ。0.25・0.5・1・2倍速。
- **クリップ保存**：全コマを `.sparkclip` ファイルに保存。保存先を選べます。
- **開く**：保存したクリップを読み込み、再び操作・再生。
- **↗**：最後に保存／読み込みしたクリップを共有。
- **1枚を保存・共有**：選んだ写真をJPEG保存し、「追加で選ぶ／残りを破棄」の確認後に共有メニューを表示。
- **カメラへ**：次の撮影へ。

1枚をJPEG保存したあとも、「追加で選ぶ」を選べば全コマが残るので、クリップ保存もできます。
クリップを保存せずカメラへ戻る・別のクリップを開く場合は、コマの破棄を確認します。
保存済みファイルは、メモリ上のコマを破棄しても消えません。

JPEGの保存先は `Pictures/SparkCapture`。Android 8・9ではストレージ権限が必要です。
メール添付は共有メニューからメールアプリを選びます。送信操作はメールアプリで行います。

## シャッター入力

本体のカメラキー・音量キー、対応する自撮り棒／ヘッドセットのキー入力で撮影できます。
2段階のカメラキーは全押し、長押しは初回だけ反応します。
アプリが前面にあり撮影できるときだけ動作します。選択・再生・保存中は再撮影しません。
端末やアダプタがAndroidへキーを送らない場合や、OSが他のアプリへ渡す場合には反応しません。

## クリップ形式

`.sparkclip` はバージョン付きZIP形式です。

- `manifest.properties`：形式名、バージョン、コマ数、シャッターからの相対時刻（ns）
- `frames/001.png` 以降：向きを補正した白黒画像。PNGなので保存時の画質劣化はありません。

ファイルはアプリの「開く」から選択します。ファイル管理アプリのタップで自動的にこのアプリが起動する関連付けはありません。
拡張子を `.zip` に変えて展開すると画像を取り出せます。読み込み時は元の `.sparkclip` を使ってください。
共有アプリが拡張子を変えても、「開く」で正しい中身のファイルを選べば読み込めます。
対応形式は現時点でバージョン1、1〜120コマ、シャッター直前1秒以内です。
過大な画像・不正な順序・未対応の形式は読み込みを中止し、直前のコマは保持します。
0.1のZIP形式とは異なります。

保存先アプリによって共有や継続的なアクセスの対応が異なる場合があります。
↗から共有できないときは、保存先のファイル管理アプリから共有してください。

## 保存・再生について

保存前のコマはメモリ内だけにあります。アプリやプロセスが終了すると失われるため、残したい場合はクリップ保存してください。
画像受信時刻をもとに再生間隔を調整します。描画負荷による遅れや、およそ60コマ/秒の表示上限があります。
再生は常に両端で折り返す往復ループです。スライダーやコマ送りを触ると停止します。

撮影は15・30・60fpsから希望速度を選びます。実測値は端末・明るさ・負荷に依存します。
短い出来事はフレーム間や露光の外に入り、記録されない場合があります。
アプリを離れると撮影・再生を停止します。
既存の写真や旧版の内部ZIPは、この更新では削除しません。

## 検証

クリップの往復変換・時刻保持、不正／過大／不足／並び違いのデータの拒否、再生のループ・往復・速度、
シャッターキーの重複防止をホスト側テストで確認しています。
ソースのコンパイル、DEX生成、APK署名、前版との署名一致も確認しています。
今回追加したAndroidのファイル選択・PNG読み込み・表示・共有の実機動作は未検証です。

## 開発

Android Studioで開き、Android SDK 35、JDK 17以降、Gradle 8.9 / Android Gradle Plugin 8.7.3でビルドします。
配布APKの署名鍵はソースに含みません。
`tests/` のテストは `ClipArchive.java`・`Playback.java`・`ShutterKeys.java` と一緒にJava 8以降でコンパイルし、
`jp.sparkcapture.ClipArchiveTest`、`jp.sparkcapture.PlaybackTest`、`jp.sparkcapture.ShutterKeysTest` を実行します。
