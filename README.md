# スパークキャプチャ 0.2（試作）

[Android用APKをダウンロード](https://github.com/mo201602-max/spark-capture/raw/refs/heads/main/downloads/sparkcapture-0.2.apk)

インパルス試験のスパーク箇所を確認するためのAndroidアプリです。
Android 8.0以降に対応し、シャッター直前1秒の低解像度・白黒画像から、必要な1枚をJPEGで残します。

## インストール・更新

Android端末で上のAPKリンクを開き、ダウンロードしたAPKをインストールしてください。
必要に応じて、APKを開くアプリに「不明なアプリのインストール」を許可してください。
0.1と同じ署名を使っているので、そのまま上書き更新できます。

## 使い方

1. カメラを許可して、対象を画面に収めます。
2. 希望する速度（15・30・60fps）を選び、「待機中」になるまで待ちます。
   実際の速度は「実測fps」を確認してください。対応しない速度は近い設定になります。
3. 音がしたら、大きな「撮影・直前1秒を確定」ボタン、または対応する外部シャッターを押します。
4. スライダーか「前のコマ／次のコマ」で必要な瞬間を選びます。
5. 「この1枚を保存して共有」を押します。選んだ写真だけが `Pictures/SparkCapture` に保存されます。
   Android 8・9では、初回のみ写真保存用のストレージ権限を許可してください。
6. 残りのコマがある場合、追加で選ぶか破棄するかの確認が出ます。
   - **追加で選ぶ**：残りのコマを保持します。共有からアプリに戻ると、次の写真を選べます。
   - **残りを破棄**：保存済みの写真を残し、未保存のコマをすべてメモリから除きます。
7. どちらを選んでも、保存した写真の共有メニューが開きます。メールアプリを選ぶとJPEGを添付できます。
   メールの送信はメールアプリ側で行ってください。共有をキャンセルしても保存した写真は残ります。
8. 「撮影を再開」で次の撮影に戻ります。未保存のコマがある場合は、破棄前に確認します。

「保存した写真を共有」から、最後に保存した写真を再び共有できます。
それ以前の写真は、端末のギャラリー／フォトアプリで確認できます。

## 本体・外部シャッター

アプリを前面に表示して「待機中」のとき、次のAndroidキー入力で撮影できます。

- 本体のカメラキー（2段階式は全押しで撮影）
- 音量＋／音量−キー
- 有線イヤホン端子や変換アダプタ経由で届くヘッドセットボタン／再生・一時停止キー
- 同じキー入力を送るBluetoothリモコン・自撮り棒

長押しのリピートやキーを離したときには重複撮影しません。
写真の選択中・保存中・共有中は、外部キーで次の撮影を始めません。
アプリ前面では、対応キーを音量調整や音楽操作ではなく撮影入力として扱います。
端末・アダプタ・リモコンがAndroidへキーイベントを送らない場合には対応できません。
通話中や他の音楽アプリの利用中など、OSが入力を他アプリへ渡す場合もあります。

## 保存と破棄

- 新しい撮影では、全コマのZIPや一時的な写真ファイルを自動保存しません。
- 選択前のコマはメモリ内だけに保持します。アプリが終了したりOSに終了されたりすると失われます。
- 共有アプリへ移って戻った場合は、アプリのプロセスが維持されていれば残りを引き続き選べます。
- 保存失敗時はコマを保持し、保存途中の画像を削除して再試行できるようにします。
- 保存したJPEGは端末の写真として残ります。共有や残りのコマの破棄では消えません。
- 0.1で保存した内部ZIPは、この更新では削除しません。0.2には旧ZIPの書き出し機能はありません。

## 検証状況と制限

ソースのコンパイル、DEX生成、APK生成・署名検証、0.1との署名一致、
外部キーの認識・長押し／キー解放の重複防止テストを実施しています。
今回の変更について、実機でのギャラリー保存・メール添付・外部リモコン動作は未検証です。

15fpsは約67ms、30fpsは約33ms、60fpsは約17ms間隔です。
短時間の放電はフレーム間や露光の外に入り、写らない場合があります。
60fpsは通常のCamera2セッションで対応する端末に限ります。実測fpsは明るさや端末負荷にも依存します。
直前1秒はアプリの画像受信時刻基準です。ボタンを押すのが1秒以上遅れるとイベントは範囲外になります。
色は記録しません。アプリを離れるとカメラ撮影を停止します。

## ソースからのビルド

Android Studioでこのフォルダを開き、Android SDK 35、JDK 17以降、
Gradle 8.9 / Android Gradle Plugin 8.7.3で同期してAPKをビルドします。
配布APKの試作用署名鍵はソースに含めていません。

ホスト側のキー入力テストは、`ShutterKeys.java` と `tests/ShutterKeysTest.java` をJava 8以降でコンパイルし、
`jp.sparkcapture.ShutterKeysTest` を実行してください。
